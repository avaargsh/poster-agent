# 图层画布

启动本地服务后打开 `/canvas`，或从工作台侧栏进入“图层画布”。

```bash
uv run --locked python -m app.run_local --port 8000
```

上传商品图片并填写标题、活动价，可选填写按钮文案。创建后，文字、商品图和装饰分别作为独立图层显示。图层列表和画布都能选择元素，右侧属性面板可修改文案、位置、尺寸、颜色、字号和透明度。

拖动结束、锁定、调整顺序和点击“保存修改”都会通过已有设计命令生成版本。活动价使用专门的改价命令，并记录本次用户输入。撤销和重做同样生成递增版本。

属性草稿会在本页的图层切换、拖动、锁定和排序之间保留，状态栏提示尚未保存的修改。服务端已保存的位置等字段会同步更新。点击“保存修改”提交当前图层的属性草稿。关闭页面时，浏览器会对尚未提交的属性草稿给出提示。

创建或打开设计后，网址中的 `document` 参数记录设计 ID，刷新会载入服务端的最新已保存版本。浏览器保存最近10份设计的 ID 和标题。也可展开“打开已有设计”输入 ID。显式打开设计或放弃草稿并载入最新版本，会使用服务端已保存的数据重新建立编辑状态。

保存结果无法确认时，可点击“重试原保存请求”，该操作复用相同 command_id。版本冲突会保留当前输入并提示载入最新版本。预览加载失败时，已确认保存的文档版本仍可恢复，并可单独重试预览。

画布使用服务端固定版本 SVG。预览会适应窗口，放大后可在画布区域滚动，缩放不改变文档尺寸。“打开 SVG 预览”读取当前版本。预览字体由浏览器与本机字体解析。批准后导出 PNG 的接口说明见 [审批版本导出](design-approved-raster.md)。

## 开发与验证

```bash
cd frontend
npm ci
npm run test:canvas
npm run build
```

独立入口为 `src/canvas-main.tsx`，构建到 `app/static/canvas/`，并生成 `app/templates/canvas.html`。`npm run check` 同时检查工作台与画布的已提交构建产物。

真实浏览器回归使用程序生成的商品像素和独立临时服务，覆盖创建、编辑、拖动取消、锁定、排序、撤销重做、刷新、版本冲突、保存响应丢失、迟到响应、断网、属性草稿保留和移动端布局。

```bash
uv run --no-sync --with 'playwright>=1.55,<2' python tests/browser_canvas_workspace.py
```

可选传入已隔离的服务地址和截图目录。浏览器可使用系统 Chrome，找不到时需预先安装 Playwright Chromium。`ci:browser` 任务包含这条回归流程。

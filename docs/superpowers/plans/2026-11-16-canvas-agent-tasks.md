# 画布自然语言修改任务

本轮由实施方选择复用已验证的 Codex 账号宿主，提供首个内置自然语言编辑入口。用户需求与当前保存版本绑定，模型输出进入已有建议预览和确认流程。

## 约束与状态

- 默认关闭，通过服务启动环境显式启用。模型使用本机 Codex 账号，HTTP 后端地址由启动配置固定为 loopback origin。
- 每次任务最多执行120秒、12次 MCP 工具调用；关闭 Shell、插件、连接器、浏览器与图像文件工具，使用临时只读宿主配置。
- MCP 子进程限制设计 ID、基础版本、请求 ID 和建议状态查询。模型仅能读取设计、提出建议和读取本次建议状态。
- SQLite 持久化 RUNNING、SUCCEEDED、FAILED、CANCELLED、UNKNOWN。相同请求复用状态，变更参数冲突。单进程同时执行一个任务。中断恢复保持待核对，新的模型调用由用户再次提交。
- 停止会结束本次进程组，已进入建议存储的候选保留供单独查看。关闭面板后任务继续，刷新可恢复状态。
- 界面说明账号及文本/图层/素材元数据的数据流，输入草稿在本页面板切换时保留。生成结果复用差异预览、显式应用和版本检查。

## 验证

用 CLI 替身和真实 HTTP/浏览器覆盖提交、丢失响应重试、幂等、停止、关闭重开、刷新、超时、重启、跨设计拒绝和状态完整性。用真实 MCP SDK 验证 scope 与预算。使用程序素材执行一次真实 Codex 账号任务，并单独核验模型输出、画布预览及原版本。自动 CI 使用本地替身。

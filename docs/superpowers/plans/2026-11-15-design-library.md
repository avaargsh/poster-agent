# 持久设计库

沿用本机单用户设计存储，补齐画布与 MCP 的设计发现入口。由实施方选择按创建时间倒序的游标分页，编辑设计时列表顺序稳定。

## 契约

- `GET /api/designs?limit=20&cursor=<document_id>`，limit 为 1–50。返回 `designs` 与可空 `next_cursor`。每条包含 document_id、当前 revision、当前标题、created_at、updated_at 与画布链接。游标是上页最后一条设计 ID，对应不可变创建时间和 ID 排序键。未知或非法游标返回 422。
- 列表读取同一 SQLite 快照中的 head 与 revision，最多解析 limit+1 条。增加可兼容既有数据库的创建顺序索引。列表不读取图片文件。
- MCP 增加只读 `list_designs`，提供绝对画布链接，复用 HTTP 查询参数和边界。
- 画布侧栏提供持久设计列表、刷新、加载更多、空状态与重试。读取失败保留已载入列表。异步过期响应被取消，刷新重置分页。打开设计继续沿用未保存草稿提示与既有打开入口。

## 验证

先验证分页缺口，再实现仓库/API/MCP 和画布。覆盖同时间排序、页间新增与修改、当前版本标题、重开仓库、非法游标、上限、跨源边界、MCP 真实协议、浏览器清空最近记录后重新发现设计、翻页和失败恢复。执行完整回归、前端产物检查及 CI，审阅后合并。

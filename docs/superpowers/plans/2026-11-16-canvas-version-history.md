# 画布历史版本与恢复

提供有界历史列表、固定版本只读预览和显式恢复。实施方选择将恢复纳入现有命令事务，复用幂等与乐观锁。

- `GET /api/designs/{id}/revisions?limit=20&cursor=<revision>`，按版本倒序分页，返回当前 head、摘要和可空下一页游标。旧数据直接可读。
- `restore_revision` 独占一个命令批次，目标为同一设计的更早版本。读取并校验历史素材，复制内容到递增的新版本，撤销栈保留恢复前版本，清空重做栈。完整快照包括图层锁和业务事实，审批记录按精确新版本重新核对。
- MCP 提案沿用已有受限操作集合。画布恢复复用用户命令、保存核对和原请求重试。
- 历史预览通过独立模式展示，预览期间禁用画布编辑与导出。恢复按钮要求成功加载预览。存在属性草稿时，按钮明确说明放弃草稿。
- 验证分页、重开、撤销重做、重复恢复、并发冲突、素材损坏和旧审批失效。浏览器覆盖预览只读、恢复确认、响应丢失、草稿及手机布局。完整回归与 CI 通过后合并。
